Frequently asked questions

Does it connect to Microsoft services?

No. html-docx-js creates the output Blob in this browser.

Is all CSS preserved?

Common inline styles work best; external CSS, scripts and animations are not DOCX features.

Is the original HTML modified?

No. The tool reads the content and creates a new DOCX file.
