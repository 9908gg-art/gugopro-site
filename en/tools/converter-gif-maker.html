Frequently asked questions

Is there a file-size limit?

There is no server upload limit in this browser tool, but memory and GIF encoding cost limit practical frame counts.

Can I import a GIF as a frame?

This first version focuses on static image frames; animated GIF decoding is browser-dependent and is not promised frame by frame.

Why do different image sizes show black bars?

Frames are scaled proportionally and centered on one output canvas; black fills the remaining area for consistent dimensions.
