Frequently asked questions

How should I name CSV columns?

Use label,x,y,r; r is optional and a fixed radius is used when it is omitted.

Is the trend line a forecast?

No. It is a local linear-regression aid for the entered points and is not a future forecast.

Is data sent remotely?

No. Parsing, regression and Canvas rendering all run in the browser.
