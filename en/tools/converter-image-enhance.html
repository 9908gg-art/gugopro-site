Features and usage guide

What is this tool for?

Tune sharpness, contrast, brightness, saturation, denoise and warmth locally with a before/after split preview and high-resolution PNG export.

Privacy statement

Your image remains in the current browser session. Preview and export use local File, Canvas and Blob APIs.

There is no file-upload endpoint; speed depends on your device and browser support.

Frequently asked questions

Are my images uploaded?

No. The page uses browser APIs and does not send image bytes to a server.

Will the original file be changed?

No. All exports are new Blob or Canvas results; the selected source file remains unchanged.

Which browsers work best?

Use a current desktop or mobile browser with Canvas and File API support. Large images may require more device memory.
