Frequently asked questions

Can different formats be merged?

Yes, as long as the browser can decode them. The output is packaged as the selected WAV or MP3.

How is order determined?

The initial order follows file selection order, and each row has move-up and move-down controls.

Does the merger add fades automatically?

No. It performs seamless sample joining; use the fade tool first when you need smooth transitions.
