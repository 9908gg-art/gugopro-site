Frequently asked questions

Are transparent PNGs supported?

Common browser-decodable images are supported. The picker shows RGB; alpha is not included in the HEX code.

How is the palette generated?

The tool samples an even grid on the Canvas for quick exploration; it is not a replacement for professional color management.

Can I download the palette?

You can copy the selected code. Use the existing Color Converter if you need a CSS palette export.
