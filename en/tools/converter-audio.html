 Format guide
WAV preserves lossless quality; MP3 is compact for sharing; OGG Vorbis is an open format suited to web audio.
Sample-rate compression
Lower sample rates reduce file size but may remove high-frequency detail; keeping the original skips resampling.
 Privacy promise

        Features and usage guide

Use Web Audio API to decode, resample and compress WAV, MP3 and OGG locally, with MP3 bitrate and OGG quality controls.

 Privacy statement

            
Audio is handled in the current page with Web Audio and browser encoders; it never leaves the device.

            
There is no file-upload endpoint; practical speed depends on device performance and browser support.

        

    

    

        
 Frequently asked questions

        
Can every audio format be decoded?
Source support depends on the browser Web Audio decoder. Common WAV, MP3 and OGG files usually work; M4A support varies.
Is audio uploaded?
No. Decoding, resampling and encoding run on the current device.
Are large files limited?
There is no server upload cap, but long audio uses more memory and CPU. Test a short clip first.
