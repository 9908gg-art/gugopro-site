 How it works
Choose a file first, then select an output format. Auto mode chooses the opposite format from the original extension.
Delay adjustment
Use −100 / +100 for quick adjustments or enter an exact millisecond value. Time will not move earlier than 00:00:00.

                
 Privacy promise
Reading and export use the browser File API and Blob. There is no upload API and subtitle content is not saved.

            

        

        

    


    

        Features and usage guide
        
What is this tool for?

        
Convert SRT ⇄ VTT, export clean TXT scripts and shift timing in milliseconds for caption review and post-production.

    

    

        

            
 3-step quick guide

            
  1. 1
    Choose or drop an SRT / VTT subtitle file.
  2. 2
    Select the output format and a positive or negative millisecond offset.
  3. 3
    Run the conversion, preview the result and download it.

        

        

            
 Privacy statement

            
Subtitle text never leaves the device, is not stored, and has no remote upload endpoint.

            
There is no file-upload endpoint; practical speed depends on device performance and browser support.

        

    

    

        
 Frequently asked questions

        
Are my subtitles uploaded?
No. Subtitle text is read by the browser File API and the result is generated locally as a Blob.
How many files can I process?
The single-file page is designed for careful editing; use the subtitle batch synchronizer for multiple files.
Does the source need a strict format?
Standard SRT or VTT timecodes are recommended. Incomplete blocks are preserved where possible and reported in the status line.
