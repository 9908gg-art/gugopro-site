Features and usage guide

What is this tool for?

Select many images or drop a folder selection, convert to WEBP, JPG or PNG, compress by quality and package the results with JSZip.

3-step quick guide

  1. 1
    Select multiple images or drop a folder selection into the batch list.
  2. 2
    Choose an output format and quality, then review each file status.
  3. 3
    Run the batch conversion and download one ZIP when complete.

Privacy statement

The file list, Canvas outputs and ZIP packaging remain on the device with no upload endpoint.

There is no file-upload endpoint; practical speed depends on device performance and browser support.

Frequently asked questions

Is the folder uploaded?

No. Folder drag-and-drop only adds the local File objects exposed by the browser.

Which images are supported?

Common PNG, JPG, WEBP and static GIF frames supported by the browser can be processed. Transparency and animation vary by output format.

Is the ZIP generated on a server?

No. Canvas, File and JSZip generate each Blob and the ZIP in the browser.
