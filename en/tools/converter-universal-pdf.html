Features and usage guide

What is the Universal PDF tool for?

Use jsPDF and SheetJS to assemble mixed local files into a downloadable PDF without sending data to a third-party service.

3-step quick guide

  1. 1
    Select one or more image, spreadsheet or text files.
  2. 2
    Choose A4, Letter or A5, portrait or landscape, and a margin.
  3. 3
    Build the PDF locally, confirm completion and download it.

Privacy statement

Selected files stay in this browser tab. Preview, conversion and export use local File, Canvas, Blob or Web Crypto APIs.

No upload endpoint is used; speed depends on your device and browser support.

Frequently asked questions

Are files uploaded?

No. Images, spreadsheets and text stay in the current browser tab.

Can I mix formats?

Yes. Each file is converted into an image, table text or text page in one PDF.

Why can large files be slower?

PDF generation uses device CPU and memory; large images or workbooks need more local resources.
