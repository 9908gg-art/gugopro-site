Frequently asked questions

Are all worksheets included?

This tool converts the first worksheet; split a workbook first if you need separate sheets.

Are cell styles preserved?

Displayed values and table content are retained, not every Excel visual style.

Is the data uploaded?

No. SheetJS parses the workbook locally.
