Features and workflow

Why this tool fits image workflows

Split images into 4, 9 or 16 grid tiles, then package the Canvas slices into a local ZIP.

3-step quick guide

  1. 1
    Drop one or more images and confirm the file list.
  2. 2
    Choose 4, 9 or 16 tiles and a filename prefix.
  3. 3
    Split locally and download the generated ZIP.

Zero-upload privacy

Files are read locally; slice Blobs and the ZIP are generated by Canvas and JSZip.

Images are not sent to external servers; speed depends on device performance and browser support.

Frequently asked questions

Can I split multiple images?

Yes. Choose multiple images; each source gets its own folder inside the ZIP.

Will the image be stretched?

No. Each tile maps directly to an original pixel region without stretching.

Why does ZIP generation take time?

PNG encoding and ZIP packaging run locally, so time depends on image size and device performance.
