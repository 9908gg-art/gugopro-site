Features and usage guide

What is this text converter for?

This server-free text workbench helps clean pasted data, inspect URL parameters and view Unicode code points.

3-step quick guide

  1. 1
    Paste text into the input box.
  2. 2
    Choose a full/half-width, language, URL or Unicode transformation.
  3. 3
    Copy the result or download TXT; the source stays in the browser.

Privacy statement

Selected files stay in this browser tab. Preview, conversion and export use local File, Canvas, Blob or Web Crypto APIs.

No upload endpoint is used; speed depends on your device and browser support.

Frequently asked questions

Does Traditional/Simplified conversion cover every term?

It includes a useful common-character map; review proper nouns and regional terminology manually.

What if URL Decode fails?

Check that the input is a complete, valid percent-encoded string and try again.

What does Unicode output look like?

Characters are shown as U+XXXX code points and can be decoded back into text.
