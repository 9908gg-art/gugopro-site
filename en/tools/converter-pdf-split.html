Features and usage guide

What is this tool for?

Read PDF page counts with pdf-lib and extract ranges such as 1-3, 5; multiple PDFs can be processed into a ZIP.

3-step quick guide

  1. 1
    Choose or drop one or more PDFs and confirm their page counts.
  2. 2
    Enter ranges such as 1-3, 5 and review the selected page range.
  3. 3
    Extract pages in the browser and download a PDF or multi-file ZIP.

Privacy statement

PDF bytes are parsed and exported in the current page without server upload or remote storage.

There is no file-upload endpoint; practical speed depends on device performance and browser support.

Frequently asked questions

Are PDFs uploaded?

No. pdf-lib reads and rebuilds PDF bytes in browser memory.

How should I write page ranges?

Use commas for single pages and ranges, such as `1-3, 5, 8-9`; pages outside the document are ignored.

Can encrypted PDFs be split?

Browser-side processing usually cannot open password-protected PDFs. Unlock them first with a trusted local tool.
