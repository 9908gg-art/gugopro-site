Chapter 5: The Cognitive Calibration Index (CCI) Mathematical Model

5.1 Formulation and Parameter Definitions

Let an individual's dilemma encompass a discrete set of action strategies $\mathcal{A} = \{a_1, a_2, \dots, a_M\}$ with prior subjective belief distribution $P = (p_1, p_2, \dots, p_M)$, where $\sum_{i=1}^M p_i = 1$. We define five core parameters:

  • Initial Decision Entropy ($H_0$): Measures baseline cognitive ambiguity using Shannon Entropy:
    $$H_0 = -\sum_{i=1}^M p_i \log_2(p_i) \quad (\text{bits}), \quad 0 \le H_0 \le \log_2(M)$$
  • Palace-Axis Coverage ($P_c \in [0, 1]$): Measures structural review across the four core life axes (Self, Resource, Career, Support):
    $$P_c = \frac{1}{K} \sum_{k=1}^K \omega_k \mathbb{I}_k, \quad K = 4, \quad \sum \omega_k = 1$$
  • Sihua Balance Factor ($S_b \in [0, 1]$): Measures whether consultations view transformations as dynamic energy conservation rather than fatalistic good vs. evil:
    $$S_b = 1 - \frac{1}{2} \sum_{j \in \{L, Q, K, J\}} \left| \phi_j - \frac{1}{4} \right|$$

    $$R_a = 1 - \frac{1}{T} \sum_{t=1}^T \frac{|\Delta G_t|}{\Delta G_{\max}}, \quad \Delta G_{\max} = 100$$
  • Actionable Testability ($\beta \in [0, 1]$): The proportion of recommendations verifiable in the real world: $\beta = \frac{N_{\text{testable}}}{N_{\text{total}}}$.
