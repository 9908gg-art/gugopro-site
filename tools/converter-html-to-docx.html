常見問題解答

會連到 Microsoft 服務嗎？

不會，html-docx-js 只在目前瀏覽器建立輸出 Blob。

所有 CSS 都會保留嗎？

常見內聯樣式較容易保留；複雜外部 CSS、互動腳本與動畫不屬於 DOCX 功能。

原始 HTML 會被修改嗎？

不會，工具只讀取內容並建立新的 DOCX 檔。
