AI 影音趨勢與跨頻道追蹤原理

生成式影片工具更新快速，從模型版本、角色一致性到短劇工作流，創作者往往需要同時觀察多個頻道才不會錯過實測與新功能。本雷達以瀏覽器直接查詢開源公共影音代理，再把結果整理成跨頻道清單；系統不保存帳號資訊，也不要求 API Key。每次搜尋都會以影片 ID 與本機快照比對，第一次出現的影片加上 NEW 標記並置頂。因公共節點可能有流量限制，頁面會依序切換備援端點；若節點全部暫時不可用，請稍後重試。追蹤條件、排除字詞、時間範圍與已見影片都只存於目前瀏覽器的 LocalStorage。

3 步驟開始

實戰 FAQ

為什麼不需要 YouTube API Key？

本工具使用開源公共影音代理的公開搜尋介面，不直接呼叫 Google API；因此不需申請或填入任何金鑰，但節點穩定度會隨公共服務狀態變化。

更換瀏覽器後追蹤資料會保留嗎？

不會。資料存在原瀏覽器與原裝置的 LocalStorage；若要換裝置，請重新建立追蹤條件。

如何過濾解說或新聞雜訊？

在排除字詞輸入新聞、教學或其他不想看的詞，搜尋結果標題含這些詞就會被排除。
