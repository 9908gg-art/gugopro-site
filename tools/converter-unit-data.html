常見問題解答

KB 和 KiB 有什麼不同？

KB 以 1000 倍進位，KiB 以 1024 倍進位；工具將兩者分列。

Bit 和 Byte 的關係？

1 Byte = 8 bits；矩陣會顯示兩者的精確換算。

能輸入極大容量嗎？

支援科學記號與 BigInt 分數運算，適合檢查大型儲存容量。

處理原理與計算方式

資料量換算必須先確認採用十進位（1 kB = 1000 bytes）或二進位（1 KiB = 1024 bytes）；網路流量常用 bit/s，檔案大小常用 byte。

三步驟使用流程

  2. 確認十進位／二進位、標準定義與顯示小數位。
  3. 將結果與領域文件或第二個可靠來源交叉核對。
