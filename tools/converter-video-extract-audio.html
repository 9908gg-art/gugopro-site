常見問題解答

提取會不會上傳影片？

不會；影片由 object URL 載入，PCM、WAV 與 MP3 都在本機建立。

為什麼要播放影片？

瀏覽器原生媒體解碼後，Web Audio API 才能安全取得播放中的 PCM samples。

WAV 與 MP3 如何選？

WAV 保留 PCM、檔案較大；MP3 較小，適合一般分享。

影片提取音訊／WAV／MP3 導出器：原理、公式與使用教學

影片提取音訊／WAV／MP3 導出器的用途：影片可視為連續影格與音軌的時間序列；輸出結果受影格率、解析度、編碼器、音訊與瀏覽器資源影響。

處理原理與計算方式

輸出音訊時長通常等於選取影片片段時長；實際編碼可能因起始關鍵影格而有些微差異。

三步驟使用流程

  1. 匯入影片並確認預覽、時長、影格率與音軌。
  2. 設定截取範圍、尺寸、速度或輸出格式。
  3. 匯出後檢查影像同步、解析度、播放相容性與檔案大小。

常見問題 FAQ

為什麼輸出時間變長或變短？

剪輯範圍、影格率、變速倍率與編碼方式都會影響輸出時長；請以播放器實際檢查。

大影片處理失敗怎麼辦？

先縮短片段、降低解析度或分批處理，避免瀏覽器記憶體不足。

輸出會保留原音軌嗎？

依工具設定而定；靜音或提取音訊工具會刻意改變音軌，其他工具仍應在輸出後確認。
