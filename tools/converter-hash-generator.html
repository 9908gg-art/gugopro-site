常見問題解答

Web Crypto API 支援 MD5 嗎？

瀏覽器 Web Crypto 標準不提供 MD5，因此頁面以本機 JavaScript 相容演算法處理 MD5；SHA-256 與 SHA-512 則使用 Web Crypto。

檔案會離開裝置嗎？

不會，檔案只以 File API 讀取位元組並在瀏覽器內計算。

生成的密碼會保存在哪裡？

不會自動保存或傳送；請使用者自行以安全的密碼管理器保存。

安全雜湊與強密碼生成器：原理、公式與使用教學

安全雜湊與強密碼生成器提供瀏覽器內的security處理流程，協助你快速完成輸入、轉換與結果檢查。

處理原理與計算方式

雜湊輸出可視為 digest = H(input)，同一輸入應產生同一摘要；雜湊不是加密，不能由摘要還原原文。密碼強度則與字元池大小 N 及長度 L 有關，理想熵約為 L × log₂(N)。

三步驟使用流程

  1. 輸入或貼上待處理資料，先確認其中不含正式密碼、私鑰、Token 或個資。
  2. 選擇演算法、格式或驗證方式，檢查頁面對金鑰、IV、編碼與輸入長度的要求。
  3. 複製結果後立即在受信任系統驗證，並清除不應留在瀏覽器歷史或剪貼簿的敏感資料。

常見問題與安全提醒 FAQ

這些工具可以取代正式的安全系統嗎？

不可以。瀏覽器工具適合檢查、教學與一次性處理；正式金鑰、密碼與權杖不應貼到不受信任的第三方頁面。

雜湊或 Base64 可以還原原文嗎？

Base64 是可逆編碼；雜湊是單向摘要，通常不能由摘要還原原文。兩者都不是同一種加密。

JWT 解碼後看到資料代表驗證成功嗎？

不代表。解碼只會讀取 payload；必須用正確的演算法與金鑰驗證簽章，並檢查 exp、iss、aud 等 claims。
