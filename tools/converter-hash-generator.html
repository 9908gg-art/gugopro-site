常見問題解答

Web Crypto API 支援 MD5 嗎？

瀏覽器 Web Crypto 標準不提供 MD5，因此頁面以本機 JavaScript 相容演算法處理 MD5；SHA-256 與 SHA-512 則使用 Web Crypto。

檔案會離開裝置嗎？

不會，檔案只以 File API 讀取位元組並在瀏覽器內計算。

生成的密碼會保存在哪裡？

不會自動保存或傳送；請使用者自行以安全的密碼管理器保存。
