功能特點與使用指南

為什麼用波形剪輯？

這個工具把整段音訊的振幅繪製成可讀波形，並將選區起訖時間直接連結到滑塊與試聽按鈕。所有解碼、剪裁與 WAV／MP3 封裝都留在目前瀏覽器。

3 步快速操作

  1. 1
    選擇或拖入音訊檔案，等待本機解碼與波形繪製。
  2. 2
    拖曳開始與結束滑塊，按試聽選取片段確認範圍。
  3. 3
    選擇 WAV 或 MP3 後導出並下載剪輯結果。

常見問題解答

支援哪些格式？

實際可解碼格式取決於瀏覽器，常見 WAV、MP3、OGG 可用，M4A 支援則依瀏覽器而異。

會上傳我的音訊嗎？

不會。檔案由 File API 讀入目前分頁，導出結果也是本機 Blob。

可以剪出 MP3 嗎？

可以。MP3 由瀏覽器端 encoder 處理；若裝置資源較少，WAV 會是更快的選擇。

視覺化音訊剪輯與裁切器：原理、公式與使用教學

視覺化音訊剪輯與裁切器的用途：數位音訊由取樣率、位元深度、聲道與編碼格式描述；品質、相容性與檔案大小需要在輸出設定間取捨。

處理原理與計算方式

輸出時長 = 結束時間 − 開始時間；剪輯邊界應落在可接受的取樣或編碼位置。

三步驟使用流程

  1. 載入音訊並確認波形、時長與聲道。
  2. 設定格式、音量、剪輯區間或效果參數。
  3. 匯出後檢查播放時長、峰值與目標裝置相容性。

常見問題 FAQ

為什麼轉換後音質不同？

有損編碼或較低位元率會丟失部分音訊資料；若要保留品質，可使用無損格式或較高位元率。

瀏覽器能處理所有音訊格式嗎？

支援度取決於瀏覽器解碼器與輸入格式；不支援的格式需先轉成常見格式。

音訊會上傳到伺服器嗎？

請依頁面隱私說明操作；本地瀏覽器工具通常直接在目前裝置處理檔案。
