功能特色與使用指南

文字編碼工具適合哪些情境？

這是一個不依賴伺服器的文字整理工作台，適合清理貼上的資料、查驗 URL 參數與查看 Unicode code point。

3 步快速操作

  1. 1
    貼上文字到輸入框。
  2. 2
    選擇全半形、繁簡、URL 或 Unicode 轉換。
  3. 3
    複製結果或下載 TXT，原始文字不會離開瀏覽器。

零上傳隱私宣告

選取檔案只留在目前瀏覽器分頁；預覽、轉換與輸出使用本機 File、Canvas、Blob 或 Web Crypto API。

頁面沒有檔案上傳端點；實際速度取決於裝置效能與瀏覽器支援。

常見問題解答

繁簡轉換是否涵蓋所有詞彙？

頁面內建常見字元對照，適合快速整理；專有名詞與地區用語仍建議人工校對。

URL Decode 遇到錯誤怎麼辦？

請確認輸入是完整且合法的 percent-encoded 字串，再重新執行。

Unicode 顯示什麼格式？

工具會以 U+XXXX 形式列出字元 code point，也能將這種格式還原成文字。
