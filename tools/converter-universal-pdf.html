選取檔案只留在目前瀏覽器分頁；預覽、轉換與輸出使用本機 File、Canvas、Blob 或 Web Crypto API。

頁面沒有檔案上傳端點；實際速度取決於裝置效能與瀏覽器支援。

常見問題解答

檔案會上傳到伺服器嗎？

不會；圖片、表格與文字只在目前瀏覽器分頁處理。

可以混合不同格式嗎？

可以；每個檔案會依格式轉成圖片、表格文字或文字頁面加入同一份 PDF。

為什麼大型檔案較慢？

PDF 產生會使用裝置 CPU 與記憶體；大型圖片或工作簿需要更多本機資源。
