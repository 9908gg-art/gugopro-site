編輯器流程是 source Markdown → parser → preview DOM；預覽結果取決於解析器支援的語法，未信任的 HTML 內容不應直接公開執行。

  3. 下載或複製輸出，在目標掃描器、編輯器或瀏覽器中抽查。

常見問題與安全提醒 FAQ

輸出可以直接公開或列印嗎？

公開前要檢查個資、機密欄位、QR／條碼內容與版面邊界；工具輸出不代表內容已完成合規審查。

為什麼預覽和下載結果不同？

可能是字型、瀏覽器渲染、畫布尺寸或解析器差異；請在目標裝置與實際播放器／掃描器中抽查。

大型資料可以一次處理嗎？

應依瀏覽器記憶體與工具限制分批處理，並保留原始檔與輸出檔的版本對照。

為什麼工具需要在瀏覽器處理？

可以，但 PDF、影像或多檔輸出會占用記憶體；手機建議降低解析度、縮小批次並保持分頁開啟至下載完成。
