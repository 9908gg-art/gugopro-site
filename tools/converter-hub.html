  1. 上傳或輸入資料，先確認格式與大小。
  2. 依畫面配置頁碼、品質、欄位或輸出格式。
  3. 執行處理，檢查預覽與狀態後下載結果。

使用者常見問題

為什麼工具需要在瀏覽器處理？

本工具將檔案解析與輸出放在目前分頁，減少上傳等待與原始資料外洩風險；裝置記憶體不足時請分批處理。

輸入格式或數值錯誤時會怎樣？

工具會在執行前檢查副檔名、必要欄位與範圍；不符合條件時顯示可理解的提示，不會下載空白結果。

手機也能使用嗎？

可以，但 PDF、影像或多檔輸出會占用記憶體；手機建議降低解析度、縮小批次並保持分頁開啟至下載完成。

Common questions

Why does this tool run in the browser?

Parsing and export happen in this tab to reduce upload delay and exposure; process large files in smaller batches if memory is limited.

What happens when input is invalid?

The tool checks file types, required fields and ranges before running, then shows a clear message instead of downloading an empty result.

Can I use it on a phone?

Yes, but PDF, image and batch exports use memory; on mobile, lower resolution, use smaller batches and keep the tab open until download completes.

よくある質問

なぜブラウザで処理するのですか？

解析と書き出しを現在のタブで行い、アップロード待ち時間と漏えいリスクを減らします。大きなファイルは分けて処理してください。

形式や数値が不正な場合は？

実行前に形式、必須項目、範囲を確認し、条件に合わない場合は空の結果を保存せず説明を表示します。

スマートフォンでも使えますか？

使えますが、PDF・画像・一括出力はメモリを使います。解像度と一括数を下げ、ダウンロード完了までタブを閉じないでください。
