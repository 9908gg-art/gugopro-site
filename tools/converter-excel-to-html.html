隱私宣告

所有 PDF／試算表／文件位元組只在目前瀏覽器分頁解析與輸出，不會傳到伺服器。

沒有檔案上傳端點；實際速度取決於裝置效能與瀏覽器支援。

常見問題解答

會輸出完整 CSS 嗎？

輸出聚焦於乾淨 table 結構；網站色彩與間距可再由你的 CSS 控制。

公式會怎麼處理？

工具使用 SheetJS 顯示值建立表格，不會執行公式。

HTML 會上傳嗎？

不會，產生與預覽都在目前瀏覽器執行。
