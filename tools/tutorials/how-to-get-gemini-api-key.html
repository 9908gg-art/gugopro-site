Google Gemini API Key 1 分鐘快速申請步驟

免費取得 Google 官方 API Key，無需綁定信用卡。 適用於任何支援 Gemini API 的工具與應用程式。

Google Gemini API Key 1 分鐘快速申請步驟

跟著以下 6 個步驟，快速取得您的免費 Gemini API Key。

1

前往 Google AI Studio 官方網站

點擊下方按鈕即可啟動 Google 帳號快速選擇器。點擊後系統會自動列出您手機或設備上已登入的 Google 帳號，直接點選即可快速進入，無須重新手動輸入帳號密碼。

提示：建議使用您常用的 Google 帳號登入，以便日後管理 API Key。
前往 Google AI Studio
2

建立 API 金鑰 (Create API Key)

登入 Google AI Studio 後，頁面左側導覽列中會看到 「Get API Key」 選項，點擊進入 API Key 管理頁面。 在頁面右上角，點擊 「Create API Key」 按鈕，系統會彈出一個對話框。

對話框會提供兩種選項：

選項 A：「Create API key in a new project」 — 建議新手選擇此選項。系統會自動為您建立一個新的 Google Cloud 專案並在其中生成 API Key，無需額外操作。
選項 B：「Create API key in existing project」 — 若您已有 Google Cloud 專案，可透過「Search Google Cloud projects」搜尋欄選取現有專案，點擊後即可在該專案下建立 API Key。若您沒有現有專案，請回到選項 A。

提示：如果您是第一次使用，強烈建議選擇「Create API key in a new project」，讓系統自動處理專案建立，流程最簡單。
3

同意服務條款 (Terms of Service)

如果您是首次使用 Google AI Studio，頁面可能會彈出 「Terms of Service」（服務條款）視窗。 請仔細閱讀條款內容，勾選同意所有必要選項後，點擊 「Continue」（繼續）按鈕完成確認。

提示：僅需首次登入時同意一次。若您過去已同意過，則不會再次出現此視窗，可直接跳至下一步。
4

確認 API Key 已成功生成

完成專案選擇後，系統會立即生成一組 API Key，以 「AIzaSy...」 開頭，顯示在對話框中。 此時對話框會提供 「Copy」（複製）按鈕，點擊即可將 API Key 複製到剪貼簿。 對話框下方也會顯示 「Done」（完成）按鈕，確認複製後點擊關閉對話框。

提示：API Key 格式通常為 AIzaSy 開頭，長度約 40 個字元。請完整複製，不要遺漏任何字元。
5

妥善保管 API Key

複製完成後，建議立即將 API Key 貼至安全的位置保存（例如密碼管理器、加密筆記本等）。 您可以在 Google AI Studio 的 API Key 管理頁面隨時查看已建立的 Key 清單。 若需要再次查看完整 Key，點擊 Key 名稱旁的 「Show」（顯示）按鈕即可。 若 Key 已洩露，可點擊 「Delete」（刪除）圖示將其移除，並重新建立一組新的 Key。

提示：請將 API Key 視為如同密碼一般的重要憑證。不要在公開場合分享、不要貼在論壇或社群媒體上。
6

貼入任何支援 Gemini API 的工具設定欄位中開始使用

取得 API Key 後，回到您所使用的工具或應用程式，找到 「API Key 設定」 或 「Settings」（設定）欄位， 將剛剛複製的 API Key 貼入即可開始使用。同一組 API Key 可在多個平台上同時使用。

常見問題 FAQ

關於 Gemini API Key 申請的常見疑問。

Q: 申請 Gemini 免費 API Key 會被扣錢嗎？
A: 完全不會。Google AI Studio 的免費版 API Key 不需要填寫信用卡資料，也不會有計費。 免費版提供充沛的 RPM（每分鐘請求數）與 TPM（每分鐘 Token 數）限額，個人使用完全足夠。
Q: API Key 遺失怎麼辦？可以重新取得嗎？
A: 可以。前往 Google AI Studio 的 API Key 管理頁面， 您可以隨時查看、刪除或重新建立新的 API Key。建議妥善保管原始金鑰，以避免服務中斷。

什麼是 Gemini API Key？

Gemini API Key 是 Google 官方提供的存取憑證，用於在呼叫 Gemini API 時驗證您的身份。 每一組 API Key 都會綁定一個 Google Cloud 專案，您可以透過 API Key 免費使用 Gemini 模型的各項功能。 免費版的限額對於個人使用與學習完全足夠。

如何安全保管 API Key？

請將 API Key 視為如同密碼一般的重要憑證。建議：不要在公開場合分享、 不要貼在論壇或社群媒體上、定期檢查 Google Cloud 專案的使用量。 如果您懷疑 API Key 已洩露，可立即前往 Google AI Studio 刪除並重新建立。
