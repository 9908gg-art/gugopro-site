免費取得 Google 官方 API Key，無需綁定信用卡。 適用於任何支援 Gemini API 的工具與應用程式。

Google Gemini API Key 1 分鐘快速申請步驟

跟著以下 4 個步驟，快速取得您的免費 Gemini API Key。

1

前往 Google AI Studio 官方網站

開啟 Google AI Studio 的 API Key 管理頁面。系統會要求您使用 Google 帳號登入。 請使用您的個人 Google 帳號（例如 @gmail.com）進行登入。

提示：建議使用您常用的 Google 帳號登入，以便日後管理 API Key。
前往 Google AI Studio
2

建立 API 金鑰 (Create API Key)

登入後，您會看到「API keys」管理頁面。點擊頁面右側的藍色 「Create API key」 按鈕。系統會詢問您要使用哪個 Google Cloud 專案。 如果您已有專案，可直接選擇；若沒有，系統會自動為您建立一個預設專案。

提示：建議選擇「Create API key in new project」，讓系統自動建立一個專屬專案，方便日後管理。
3

複製 API Key 密鑰

系統生成金鑰後，會顯示一串以 AIzaSy... 開頭的長字串。 點擊右側的 「Copy」 圖示（複製按鈕），將 API Key 複製到剪貼簿。 請妥善保管此金鑰，不要分享給他人。

提示：API Key 格式通常為 AIzaSy 開頭，長度約 40 個字元。請完整複製，不要遺漏任何字元。
4

貼入任何支援 Gemini API 的工具設定欄位中開始使用

取得 API Key 後，回到您所使用的工具或應用程式，找到 「API Key 設定」 或 「設定」 欄位， 將剛剛複製的 API Key 貼入即可開始使用。同一組 API Key 可在多個平台上同時使用。

常見問題 FAQ

關於 Gemini API Key 申請的常見疑問。

Q: 申請 Gemini 免費 API Key 會被扣錢嗎？
A: 完全不會。Google AI Studio 的免費版 API Key 不需要填寫信用卡資料，也不會有計費。 免費版提供充沛的 RPM（每分鐘請求數）與 TPM（每分鐘 Token 數）限額，個人使用完全足夠。
Q: API Key 遺失怎麼辦？可以重新取得嗎？
A: 可以。前往 Google AI Studio 的 API Key 管理頁面， 您可以隨時查看、刪除或重新建立新的 API Key。建議妥善保管原始金鑰，以避免服務中斷。

什麼是 Gemini API Key？

Gemini API Key 是 Google 官方提供的存取憑證，用於在呼叫 Gemini API 時驗證您的身份。 每一組 API Key 都會綁定一個 Google Cloud 專案，您可以透過 API Key 免費使用 Gemini 模型的各項功能。 免費版的限額對於個人使用與學習完全足夠。

如何安全保管 API Key？

請將 API Key 視為如同密碼一般的重要憑證。建議：不要在公開場合分享、 不要貼在論壇或社群媒體上、定期檢查 Google Cloud 專案的使用量。 如果您懷疑 API Key 已洩露，可立即前往 Google AI Studio 刪除並重新建立。
