常見問題解答

HTML 預覽安全嗎？

預覽會移除 script、iframe、form 與事件屬性，避免不必要的執行。

內容會被保存嗎？

不會。文字只在目前分頁的輸入框與預覽區存在。

支援完整 Markdown 嗎？

內建常用標題、段落、清單、引用、連結、粗體、斜體與程式碼區塊；複雜擴充語法可能需要專用 Markdown 引擎。

Markdown 雙向轉換器：原理、公式與使用教學

Markdown 雙向轉換器提供瀏覽器內的text處理流程，協助你快速完成輸入、轉換與結果檢查。

處理原理與計算方式

Markdown 轉換的核心是語意映射：標題、清單、連結與程式碼區塊會依語法標記轉成 HTML，反向轉換則只能保留可辨識的結構，複雜 CSS 不一定能還原。

三步驟使用流程

  1. 輸入文字、Markdown 或文件片段並確認字元編碼。
  2. 選擇轉換、格式化或編解碼模式，預覽差異與特殊字元。
  3. 複製或下載結果，於目標系統再次解析並核對內容。

常見問題與安全提醒 FAQ

轉換後格式跑掉怎麼辦？

先確認來源的標題、清單、表格與特殊字元是否使用工具支援的語法，再於目標平台預覽並手動修正複雜結構。

編碼工具會刪除原始內容嗎？

正常輸出會建立新結果，不應覆寫原文；處理重要資料前仍建議保留原始副本。

資料會被上傳嗎？

請依頁面隱私說明操作；本地轉換工具通常在瀏覽器執行，但敏感內容仍應避免貼入未知服務。
