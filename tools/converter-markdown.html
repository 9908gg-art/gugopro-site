常見問題解答

HTML 預覽安全嗎？

預覽會移除 script、iframe、form 與事件屬性，避免不必要的執行。

內容會被保存嗎？

不會。文字只在目前分頁的輸入框與預覽區存在。

支援完整 Markdown 嗎？

內建常用標題、段落、清單、引用、連結、粗體、斜體與程式碼區塊；複雜擴充語法可能需要專用 Markdown 引擎。
