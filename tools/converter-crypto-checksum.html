常見問題解答

檔案會上傳嗎？

不會，檔案以 File API 在目前分頁讀取。

應使用哪一種雜湊？

新流程優先 SHA-256；MD5 與 SHA-1 只建議用於核對既有舊資料。

比對大小寫有差嗎？

工具會以小寫形式顯示雜湊並進行不分大小寫的比對。
