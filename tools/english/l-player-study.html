    讓輸入變成可回收的語音訓練

    逐句精聽的價值，不只是把影片放慢，而是把注意力收斂到一個可處理的語音單位：先聽辨連音、重音與句尾，再用字幕確認假設，最後立即模仿。這個循環能讓大腦同時建立聲音、文字與語意的對應，減少「看得懂卻聽不出來」的落差。當你開啟影子跟讀（Shadowing），要在原音之後快速複述，口腔動作、節奏與工作記憶會一起參與；持續練習能讓常見語塊從刻意思考逐漸變成可自動提取的語音迴路。建議先以 0.75× 熟悉音節，再回到 1.0×，每句循環三至五次，最後關掉字幕檢查自己能否只靠聲音理解。這套播放器把跳轉、循環與句尾停頓放在同一個視野，讓每次練習都短、準確，而且容易重複。

    常見問題

    開始前，你可能想知道

    使用這款播放器需要支付任何費用或申請 API Key 嗎？

    不需要。播放器使用 YouTube 官方 IFrame Player API 載入影片，不要求使用者申請或輸入 API Key；字幕解析在你的瀏覽器本機完成。

    如果影片本身沒有字幕，我可以如何搭配練習？

    你可以下載或自行準備 SRT／VTT 字幕檔，再使用匯入字幕功能載入；也可以貼上字幕文字後由本機解析。

    我上傳的自訂字幕或觀看紀錄會被上傳到伺服器嗎？

    不會。自訂字幕只留在目前瀏覽器分頁的記憶體中，播放器不會將字幕或觀看紀錄上傳到 GugoPro 伺服器。
