功能特色與使用指南

這個工具適合什麼工作？

在瀏覽器本地調整銳化、對比度、亮度、飽和度、去噪點與暖色調，提供調整前後分割預覽與高解析度 PNG 導出。

3 步快速操作

  1. 1
    選擇本機圖片並確認檔案資訊。
  2. 2
    調整控制項，檢查瀏覽器中的即時預覽。
  3. 3
    在本地導出結果，原始檔案不會被修改。

隱私宣告

圖片只存在於目前瀏覽器工作階段，預覽與輸出都使用本機 File、Canvas 與 Blob API。

沒有檔案上傳端點；實際速度取決於裝置效能與瀏覽器支援。

常見問題解答

圖片會被上傳嗎？

不會。本頁使用瀏覽器 API，不會把圖片位元組傳送到伺服器。

原始檔案會被修改嗎？

不會。所有輸出都是新的 Blob 或 Canvas 結果，選取的原始檔保持不變。

哪些瀏覽器最適合？

建議使用支援 Canvas 與 File API 的最新版桌面或手機瀏覽器；高解析度圖片可能需要較多裝置記憶體。
