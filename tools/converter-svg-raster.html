功能特色與使用指南

SVG 點陣化會上傳嗎？

SVG 文字會先在瀏覽器內做基本安全清理，再交由 Canvas 依倍率輸出，不使用伺服器轉檔。

3 步快速操作

  1. 1
    選擇或拖曳 SVG 檔案並確認預覽。
  2. 2
    設定 1x、2x、4x 或 8x 與透明 PNG/白底 JPG。
  3. 3
    按本地轉圖，完成後下載高清檔。

零上傳隱私宣告

選取檔案只留在目前瀏覽器分頁；預覽、轉換與輸出使用本機 File、Canvas、Blob 或 Web Crypto API。

頁面沒有檔案上傳端點；實際速度取決於裝置效能與瀏覽器支援。

常見問題解答

可以輸出透明背景嗎？

可以，選擇 Transparent PNG 會保留透明背景；JPG 會先填入白色背景。

8x 會不會太大？

倍率越高，像素與記憶體需求越大；若裝置較慢，建議從 2x 或 4x 開始。

SVG 中的外部圖片會怎樣？

頁面會移除外部或資料 URI 參照，以降低非預期資源載入並維持本機處理。
