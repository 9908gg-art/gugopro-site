圖片合併轉 PDF：原理、計算方式與使用教學
將多張圖片依指定順序整理成單一 PDF，適合掃描文件、收據與簡報素材歸檔。
原理與公式
輸出頁數 = 圖片數；若每張圖片尺寸為 W × H，頁面比例會依版面設定縮放，原圖像素不會因縮放公式而增加。
三步驟使用流程
  1. 選取 PNG、JPG 或 WebP 圖片並確認檔名排序。
  2. 設定頁面尺寸、方向與邊距，預覽每一頁的裁切結果。
  3. 執行匯出並下載 PDF，完成後用頁數與檔案大小快速複核。
常見問題 FAQ
圖片順序可以調整嗎？
可以。工具依檔名與選取順序建立頁面，匯出前應先確認縮圖順序。
為什麼 PDF 變大？
PDF 會保存每張圖片的像素資料；高解析度或未壓縮圖片會增加檔案大小，可先縮小圖片或選擇壓縮設定。
圖片會上傳到伺服器嗎？
本工具在瀏覽器中處理檔案；除非頁面另有明示，原始圖片不會由本工具主動上傳。

使用者常見問題
為什麼工具需要在瀏覽器處理？
本工具將檔案解析與輸出放在目前分頁，減少上傳等待與原始資料外洩風險；裝置記憶體不足時請分批處理。
輸入格式或數值錯誤時會怎樣？
工具會在執行前檢查副檔名、必要欄位與範圍；不符合條件時顯示可理解的提示，不會下載空白結果。
手機也能使用嗎？
可以，但 PDF、影像或多檔輸出會占用記憶體；手機建議降低解析度、縮小批次並保持分頁開啟至下載完成。

Common questions
Why does this tool run in the browser?
Parsing and export happen in this tab to reduce upload delay and exposure; process large files in smaller batches if memory is limited.
What happens when input is invalid?
