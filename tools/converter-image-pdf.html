 常見問題解答

        
圖片會被上傳嗎？
不會。每張圖片由 File API 與 Canvas 在本地讀取，jsPDF 只在瀏覽器生成 PDF。
能處理多少張圖片？
沒有伺服器檔案數限制，但大量高解析圖片會消耗裝置記憶體；可分批處理以保持穩定。
可以重新排序嗎？
可以，檔案清單提供上移、下移與移除控制。
