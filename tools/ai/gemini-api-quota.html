查看配額時可核對的項目

Gemini API 的配額通常會按模型、時間窗口及指標呈現，例如每分鐘請求數（RPM）、每分鐘 token 數（TPM）或每日請求數（RPD）。可用模型、實際上限、重設時間與帳戶資格可能不同，應以 Google 帳戶控制台所顯示的資訊為準；任何第三方頁面都不應被視為配額或服務可用性的保證。

使用前注意

  1. 本入口不會要求您輸入 API 金鑰，也不會自行執行配額查詢。
  2. 前往獨立服務前，請先確認網址、服務來源及其隱私與安全說明；不要在不熟悉的頁面貼上正式金鑰。
  3. 若配額資訊將用於正式系統規劃，請再到 Google 官方控制台核對模型、帳戶方案與目前限制。

常見問題

這個頁面會查詢我的 API 配額嗎？

不會。本頁只提供轉址與一般核對指引；實際查詢入口是獨立的 Quota Hub。

Quota Hub 是 Google 官方網站嗎？

不是。本頁連往 GugoPro 網域下的獨立服務；Google 帳戶配額仍應以 Google 官方控制台為準。

看見可用額度就代表 API 一定能呼叫成功嗎？

不一定。權限、模型可用性、請求格式、帳戶設定及服務狀態都可能影響呼叫結果。
