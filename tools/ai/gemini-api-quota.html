Gemini API 官方額度查詢：原理、操作與常見問題

提供 Gemini 額度與模型狀態的相容入口；實際資料與查詢服務位於獨立 Quota Hub。

功能原理與使用限制

額度通常依模型、時間窗口與指標區分，例如每分鐘請求、每日請求或 Token 用量；實際上限與重設時間以官方帳戶資料為準。

三步驟使用指南

  1. 確認目前頁面狀態與官方 Quota Hub 連結。
  2. 依模型與時間窗口閱讀 RPD、RPM、TPM 等欄位。
  3. 將額度結果與官方控制台交叉核對，不把展示資料當成 API 保證。

實用 FAQ

這個頁面本身會取得我的 API Key 嗎？

不應在相容入口貼入正式金鑰；請依官方 Quota Hub 的登入與權限流程操作。

為什麼額度數字會變動？

額度可能依時間窗口、模型、帳戶方案與官方狀態更新。

不一定，還可能受權限、模型可用性、請求格式與服務狀態影響。
