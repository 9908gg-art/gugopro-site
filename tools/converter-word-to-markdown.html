常見問題解答

會保留 Word 的完整排版嗎？

會轉換常見文字結構，但不保證複雜版面、頁首頁尾或文字框完全保真。

DOCX 會上傳嗎？

不會，mammoth.js 在目前瀏覽器分頁中讀取檔案。

可以轉成純文字嗎？

可以，在格式選單選擇 TXT 即可。

Word DOCX 轉 Markdown / TXT：原理、計算方式與使用教學

將 DOCX 文件的標題、段落與清單轉成 Markdown 或純文字，方便版本控制與知識庫整理。

原理與公式

Markdown 結構層級 = DOCX 標題層級；清單縮排層級應與原始段落的巢狀關係一致。

三步驟使用流程

  1. 選取 DOCX 檔案並等待瀏覽器解析。
  2. 檢查標題、清單、連結與表格的轉換結果。
  3. 選擇 Markdown 或 TXT 並下載，再於目標平台預覽。

常見問題 FAQ

圖片會一起轉換嗎？

取決於頁面支援的嵌入媒體策略；重要圖片請檢查輸出是否有正確路徑或替代文字。

Word 樣式會完整保留嗎？

Markdown 著重語意結構，不會完整保留所有字型、頁首頁尾與版面設計。

表格可以轉成 Markdown 嗎？

若工具支援表格，會盡量轉成 Markdown 表格；複雜合併儲存格可能需要手動整理。
