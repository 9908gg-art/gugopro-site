 常見問題解答

        
圖片會送到雲端嗎？
不會。圖片由瀏覽器的 File API、Image 與 Canvas API 處理。
如何處理多張圖片？
單圖頁面適合逐張調整；需要多檔案與 ZIP 下載時，請使用多圖批次轉檔工具。
為什麼輸出大小會不同？
格式、尺寸與品質設定會影響 Blob 大小；JPG 與 WEBP 的有損品質也會改變檔案體積。
