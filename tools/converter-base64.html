常見問題解答

Base64 內容會離開裝置嗎？

不會。文字、圖片與 SVG 都以瀏覽器 File API、DOMParser 或 Canvas 本地處理。

SVG 為什麼會被清理？

預覽會移除 script、事件屬性與危險 javascript: 連結，降低不必要的執行風險。

DataURI 適合放大檔案嗎？

DataURI 會增加文字體積，較大的圖片更適合直接使用檔案或 CDN。
