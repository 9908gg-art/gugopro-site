常見問題解答

這些資料會上傳嗎？

不會，所有編解碼都在目前瀏覽器內完成。

UTF-8 Hex 有空格嗎？

輸出為連續兩位十六進位字元；解碼時可接受空格與 0x 前綴。

HTML Entities 會執行 HTML 嗎？

不會，工具只把字串轉換為實體或純文字，不會把輸入插入可執行 DOM。
