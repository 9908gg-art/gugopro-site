 使用方式
先選檔案，再選輸出格式。自動模式會依原始副檔名選擇相反格式。
延遲微調
用 −100 / +100 快速調整，或直接輸入更精細的毫秒數；時間不會被推移到 00:00:00 以下。

                
 隱私承諾

 常見問題解答

        
檔案會上傳到伺服器嗎？
不會。字幕文字只由目前瀏覽器的 File API 讀取，轉換結果以 Blob 在本機產生。
一次可以處理幾個檔案？
單檔字幕頁適合精準校對；若要一次處理多個檔案，請使用字幕批次同步調時器。
輸入格式需要嚴格一致嗎？
建議使用標準 SRT 或 VTT 時間碼；不完整的區塊會被保留並以狀態訊息提示。
