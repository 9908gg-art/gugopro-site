YouTube 影音「聽・寫・口說」多國語言跟讀器YouTube Immersive Multi-language Study Player

工具定位與核心優勢

這是免 API Key 的多國字幕學習工作台。它把商用逐句播放器的影音操作，結合 Echo Loop 的「盲聽 → 精聽 → 跟讀 → 複述」認知迴路，讓看懂字幕再也不是終點。獨家亮點是可自由拖曳、可調整大小的「影片文字遮罩」，能直接蓋住硬字幕做盲聽；搭配雙語對照字幕、單句循環、句尾自動暫停與「按住說話、放開比對」的發音比對。支援英語、日語、韓語、法語、德語、西語等多國語言字幕。

具體如何幫助使用者解決痛點

多數人刷了整季影片仍聽不出真實語流，因為缺少可重複、可觀察的最小練習單位。本工具把每句台詞切成一格訓練：先不看字幕盲聽，再用字幕驗證，最後用自己的聲音複述，特別適合想練英聽、日聽與口說的人。

實戰操作指引

  1. 貼上 YouTube 網址，系統自動讀取字幕時間軸。
  2. 分別選擇「學習語言」與「輔助對照」，建立雙語對照。
  3. 開啟影片文字遮罩並拖曳蓋住硬字幕，進行盲聽訓練。
  4. 用單句循環與句尾自動暫停反覆精聽，必要時微調時間軸。
  5. 在聽寫欄輸入內容，按住麥克風說話、放開即與目標句比對。

技術與隱私保護承諾

學習歷程、字幕與影片歷史以瀏覽器本機（localStorage/IndexedDB）保存，不上傳原始影音檔；字幕可手動匯入 .srt，完全免 API Key。

實戰操作指引

面對面旅遊對話翻譯Face-to-face Travel Voice Translator

工具定位與核心優勢

免安裝的手機雙向語音翻譯工具，支援 18 種語言。最大巧思是「對向 180° 翻轉」：按下翻轉視角只會旋轉對方一側的對話卡片，手機平放在桌面中央時，雙方各自從面前閱讀譯文，不必來回傳遞手機。另提供「點擊」與「對講機」兩種收音模式、重播與複製功能。

具體如何幫助使用者解決痛點

旅途中兩人輪流看同一支手機，對話被打斷、方向容易看錯，還得一直傳手機。本工具讓點餐、問路、飯店入住、購票等短句往返更順暢，維持自然的交流節奏，特別適合自由行現場溝通。

實戰操作指引

  1. 設定上方選單（對方語言）與下方選單（我方語言）。
  2. 選擇點擊模式或對講機模式，雙方輪流發話。
  3. 查看辨識文字、翻譯結果並聆聽朗讀。
  4. 按「翻轉視角」，讓對方從自己方向正面閱讀。

技術與隱私保護承諾

頁面程式不會把對話文字寫入 GugoPro 資料庫，不留存個人敏感個資。
