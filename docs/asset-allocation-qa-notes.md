# 資產配置與動態再平衡 QA

本地 `portfolio-rebalancer.html` 初始載入可見三個預設資產列、動態新增／移除、三種再平衡規則、偏離門檻、交易費率、最低費用、賣出稅費率與來源限制。透過頁面 DOM 事件觸發預設計算後，狀態為「計算完成」、產生 3 列配置結果、6 張摘要 metrics，並啟用本機 JSON 下載；console 無輸出。瀏覽器工具第一次點擊未更新結果，但在頁面內重新觸發同一 DOM click 後計算成功，屬操作同步／點擊工具層問題，不是 runtime 例外。

錯誤與恢復回歸：把股票目標權重改成 50% 使總權重降至 90% 後，工具顯示「計算未完成：目標權重目前合計 90.00%，必須等於 100%」，且結果列數與 metrics 數皆清為 0。恢復原始 60/30/10、加入 25,000 元並切換「新資金優先補低配」後，工具成功計算，產生 4 列（3 個資產＋1 列未配置／待決定資金），並保留 25,000 元可追溯的未配置金額。
