## Root causes addressed

1. Converter Hub pages previously combined a static `.converter-language-link` English/Chinese anchor with the shared runtime selector. The static anchors are removed at source.
2. Legacy finance pages previously contained `.lang-selector` / `.lang-dropdown` / `.lang-btn` menus, including pages with multiple hosts. Those hosts are removed at source; the runtime now reconciles any late-added legacy controls.
3. Fifty-seven pages previously loaded the obsolete `static-locale-runtime.js` in addition to the shared runtime. Its tags and file are removed.
4. AI pages retain catalog-backed interface or functional language controls. AI-owned health pages are detached from the generic Non-AI runtime, and the tutor's unfinished interface-language selector is removed rather than advertising untranslated UI.
5. The shared runtime now follows URL query, localStorage, navigator language, then default; `navigator.language` no longer overrides an explicit user choice.
