## 群組聚類模型

系統先以最近 60 個共同交易日的收盤價建立相關係數矩陣，再以門檻 0.85 的貪婪高相關分群法建立同盟群組。每組限制為 3 至 8 檔；每次新增成員時，該成員與既有成員的平均相關係數必須仍達到 0.85。小於 3 檔的剩餘成分不會被硬湊成模型，避免將不完整群組誤報為多元理論價。

## 多元 Beta 與理論價

對每個群組內的目標標的 Y，使用其餘群組成員作為解釋變數，估計：

```text
Y_t = Alpha + Beta_1 X1_t + Beta_2 X2_t + ... + Beta_k Xk_t + Residual_t
```

理論公允價格為：

```text
P_fair,t = Alpha + Σ(Beta_i × P_Xi,t)
```

系統輸出每一組的 Alpha、各個成分標的 Beta、目前實際價格、目前理論價格、實際價格相對理論價格的百分比偏離，以及殘差的 20 日／60 日均值、標準差、Z-Score、ADF-style p 值與半衰期。

前端價格圖中的第一條線為目標標的實際價格，第二條線為多元 Beta 合成的理論價格；兩者均以起點 100 正規化，以便直接觀察相對偏離。

## 隔日沖回測

回測完全避免使用未來資料：

1. T 日收盤後使用當時的殘差 Z-Score 判斷是否達到 `|Z| >= 2.0`。
2. T+1 日開盤以目標標的與理論價籃子建立對沖部位。
3. T+1 日收盤全部平倉，不留隔夜部位。
4. 每筆交易扣除預設雙邊總摩擦成本 0.375%。
5. 計算交易次數、獲利筆數、虧損筆數、勝率、平均風報比與累積淨報酬。

勝率定義為獲利交易筆數除以完成交易總筆數。逐筆資料會發布至獨立交易紀錄檔，前端選取群組標的後再讀取並顯示完整紀錄。

## 實盤使用注意事項

本系統仍是研究工具，不是自動下單系統。個股期貨歷史資料在免費公開端點的連續覆蓋並不完整，部分期貨使用對應現貨方向性代理；前端會保留代理提示。正式部署前應替換為券商或交易所可交易的連續期貨結算價，並處理換月、合約乘數與保證金變化。

成分股停牌、漲跌停鎖死、開盤無成交、除權息、股票借券限制與極端滑價，都可能使理論價與回測結果無法實現。當 T+1 開盤任一腿沒有有效價格時，該筆交易會被跳過；實盤還應加入最大持倉、最大群組曝險、單日損失上限、停損與資料新鮮度檢查。ADF-style p 值是研究近似值，不應視為統計保證；若要投入資金，應使用更長樣本、嚴格樣本外驗證與實際交易成本重算。

此外，群組內高相關不代表所有成分具有相同基本面。群組結構可能因產業週期、公司事件或市場制度改變而失效，故每日更新後仍應人工檢查群組成分、代理標記與資料日期。
測試報告以最新 feed 為準，並保留資料產生時間與歷史起訖日期供追蹤。
